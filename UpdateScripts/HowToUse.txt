HOW TO USE THE UPDATE SCRIPTS
==============================

Pick the folder matching your current framework version and copy it into
the ROOT of the mission you want to update. Then run run_update.bat.

  v4/   Framework 4 (current)
  v3/   Framework 3 (legacy)

Example:
  Copy v4/ into COOP10_MyMission.Altis/
  Run   COOP10_MyMission.Altis\v4\run_update.bat
  Delete v4/ from the mission folder when done.

BACKUP YOUR MISSION FOLDER BEFORE RUNNING.

What the v4 script does:
  DELETES and replaces: Gear\, Description.ext, version.hpp, Init.sqf
  Also cleans up: Core\, Modules\, Scripts\ (FW3 leftovers, if present)
  NOT touched: CustomGear\, spawnList.sqf, mission.sqm (updated in-place)

After the script finishes, paste from the FW4 template:
  Gear\, Description.ext, version.hpp, Init.sqf,
  CurrentAddonOptionsImportSettings.txt

Then import CurrentAddonOptionsImportSettings.txt in your Addon Options.

Report any issues to Oksman.
