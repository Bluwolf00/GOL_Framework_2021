HOW TO USE THE UPDATE SCRIPTS
==============================

Pick the folder matching your current framework version and copy it into
the ROOT of the mission you want to update. Then run run_update.bat.

  v4/   Framework 4 (current)
  v3/   Framework 3 (legacy)

Example:
  Copy v4/ into COOP10_MyMission.Altis/
  Run   COOP10_MyMission.Altis\v4\run_update.bat
  Delete v4/ from the mission folder when done.

BACKUP YOUR MISSION FOLDER BEFORE RUNNING.

What the v4 script does:
  Before deleting Modules\Gear, reads the selected BLUFOR/OPFOR/INDEP kits
  from mission.sqm. After the FW4 CustomGear\ folder is copied, it replaces:
    CustomGear\CUSTOM-W.sqf  (selected BLUFOR kit)
    CustomGear\CUSTOM-E.sqf  (selected OPFOR kit)
    CustomGear\CUSTOM-I.sqf  (selected INDEP kit)
  DELETES and replaces: Gear\, Description.ext, version.hpp, Init.sqf
  Also cleans up: Core\, Modules\, Scripts\ (FW3 leftovers, if present)
  NOT touched: CustomGear\, spawnList.sqf, mission.sqm (updated in-place)

After the script finishes, paste from the FW4 template:
  Gear\, CustomGear\, Description.ext, version.hpp, Init.sqf,
  CurrentAddonOptionsImportSettings.txt

Then import CurrentAddonOptionsImportSettings.txt in your Addon Options.

GEAR PORTING (FW3.1 -> FW4)
-------------------------
The updater temporarily stages the old faction kits, then restores them over
the FW4 template's CUSTOM-W.sqf, CUSTOM-E.sqf and CUSTOM-I.sqf after you copy
the CustomGear\ folder. No BLUFOR.sqf, OPFOR.sqf or INDEP.sqf files are created.

The updater also changes the Framework 4 Gear addon options in mission.sqm:
CUSTOM-W for BLUFOR, CUSTOM-E for OPFOR and CUSTOM-I for INDEP whenever that
side's selected legacy kit was restored. The migration overwrites the matching
CUSTOM faction file once, so review the update log before rerunning it.

Report any issues to Oksman.
